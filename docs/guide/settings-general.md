# Paramètres généraux

<p class="lead">L’onglet `Général` vous donne un résumé rapide de l’état de l’application, mais aussi les réglages de base pour l’apparence, la taille du texte et la langue de l’interface.</p>

## Où ouvrir cette page

1. Ouvrez `Paramètres`
2. Cliquez sur `Général`

## Ce que vous y voyez

Cette page réunit deux choses :

- des réglages simples que beaucoup d’utilisateurs changent dès le début
- un résumé rapide de l’état général de l’application

Vous y trouvez notamment :

- le mode d’apparence
- la taille du texte
- la langue de votre bibliothèque
- la langue de l’interface
- le nombre de langues installées
- l’état de la sauvegarde
- l’état de la mise à jour

## Apparence

Vous pouvez choisir entre quatre modes :

- `Automatique` : thème clair le jour, sombre le soir
- `Système` : suit l’apparence de votre ordinateur
- `Clair`
- `Sombre`

Ce réglage agit sur toute l’application.

## Taille du texte

Vous pouvez aussi choisir une taille de texte :

- `Petit`
- `Normal`
- `Grand`
- `Très grand`

Ce réglage est utile si vous lisez longtemps ou si vous travaillez sur un petit écran.

## Langue de l’interface

La langue de l’interface contrôle :

- les menus
- les boutons
- les messages affichés dans l’application

Elle est différente de la langue de votre bibliothèque de prédications.

## À quoi sert cette page

Cette page est utile si vous voulez :

- vérifier que la bonne langue est sélectionnée pour votre bibliothèque
- vérifier la langue de l’interface
- choisir rapidement un mode clair, sombre, automatique ou système
- agrandir le texte si l’affichage est trop petit
- voir rapidement si la sauvegarde fonctionne
- savoir si une mise à jour est disponible
- contrôler l’état général de l’application sans ouvrir tous les autres onglets

## Petits rappels utiles

Si certaines fonctions importantes ne sont pas encore configurées, Wmb Table peut afficher plus tard une petite notification discrète en haut de l’écran pour vous rappeler :

- l’assistant IA
- la lecture audio
- la sauvegarde

Ces rappels n’interrompent pas votre travail. Vous pouvez :

- cliquer pour ouvrir directement le bon onglet des paramètres
- ou les fermer, puis l’application vous les reproposera plus tard

## Quand revenir dans Général

Revenez dans `Général` :

- si vous voulez changer rapidement l’apparence de l’application
- si vous voulez adapter la taille du texte
- après avoir changé la langue de votre bibliothèque ou de l'interface
- après avoir activé la sauvegarde
- après avoir vérifié une mise à jour
- quand vous voulez contrôler rapidement que tout va bien
