# Comprendre l'interface

<p class="lead">Wmb Table est organisé pour que vous puissiez passer rapidement de la lecture à la préparation de votre message ou de votre étude.</p>

## Vue générale

L’écran principal est divisé en plusieurs zones.

## 1. La barre du haut

En haut de la fenêtre, vous trouverez deux vues principales :

- `Outils` : pour la recherche, les notes, les sujets, la Bible, l’assistant et les paramètres
- `Lecture` : pour lire le contenu ouvert dans les onglets

## 2. Le menu de gauche

Le menu de gauche contient les pages de travail :

- `Historique`
- `Recherche`
- `Assistant` quand la fonction IA est activée
- `Sujets`
- `Notes`
- `Soulignages`
- `Bible`
- `Paramètres`

Vous pouvez réduire ce menu si vous avez besoin de plus d’espace.

## 3. La zone centrale

Le centre de la fenêtre change selon ce que vous faites :

- si vous êtes dans `Lecture`, vous voyez une prédication, un chapitre biblique ou un document personnel
- si vous êtes dans `Outils`, vous voyez la page choisie dans le menu de gauche

## 4. Les onglets

Chaque document ouvert apparaît dans un onglet.

Cela permet de garder plusieurs lectures à portée de main :

- une prédication principale
- une autre prédication pour comparer
- un chapitre biblique
- un document personnel

## 5. La colonne de droite

Cette colonne sert à ouvrir rapidement du contenu.

Elle contient :

- `Prédications`
- `Bible`
- `Documents`

## 6. Les paramètres

Les paramètres sont séparés en plusieurs sections simples :

- `Général`
- `Vue document`
- `Langues`
- `Assistant`
- `Lecture audio`
- `Sauvegarde`
- `Mise à jour`

## 7. Notifications discrètes

Certaines informations importantes peuvent apparaître en haut de l’application sans bloquer votre travail, par exemple :

- un rappel pour configurer l’assistant IA
- un rappel pour configurer la lecture audio
- un rappel pour activer la sauvegarde
- une information de mise à jour

Vous pouvez cliquer sur ces notifications ou simplement les fermer.

## Comment bien se repérer

Retenez cette idée simple :

- à droite, vous ouvrez ce que vous voulez lire
- au centre, vous lisez
- à gauche, vous préparez votre travail
