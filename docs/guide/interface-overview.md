# Comprendre l'interface

<p class="lead">Wmb Table est organisé pour que vous puissiez passer rapidement de la lecture à la préparation de votre message.</p>

## Vue générale

L’écran principal est divisé en plusieurs zones.

## 1. La barre du haut

En haut de la fenêtre, vous trouverez deux vues principales :

- `Outils` : pour la recherche, les notes, les sujets, la Bible et les paramètres
- `Lecture` : pour lire le contenu ouvert dans les onglets

Cette barre permet de passer facilement du travail de préparation à la lecture.

## 2. Le menu de gauche

Le menu de gauche contient les pages de travail :

- `Historique`
- `Recherche`
- `Sujets`
- `Notes`
- `Bible`
- `Paramètres`

Si vous avez besoin de plus d’espace, vous pouvez réduire ce menu.

## 3. La zone centrale

Le centre de la fenêtre change selon ce que vous faites :

- si vous êtes dans `Lecture`, vous voyez la prédication, la Bible ou un document PDF converti en texte
- si vous êtes dans `Outils`, vous voyez la page choisie dans le menu de gauche

## 4. Les onglets

Chaque document ouvert apparaît dans un onglet.

Cela permet de garder plusieurs lectures à portée de main :

- une prédication principale
- un passage biblique
- un document personnel

Vous pouvez :

- changer d’onglet
- fermer un onglet
- réorganiser les onglets
- fermer les autres onglets avec le menu contextuel

## 5. La colonne de droite

Cette colonne sert à ouvrir rapidement du contenu.

Elle contient trois parties :

- `Prédications`
- `Bible`
- `Documents`

Dans cette zone, vous pouvez parcourir la bibliothèque sans quitter votre lecture actuelle.

## 6. Les paramètres

Les paramètres sont séparés en plusieurs sections simples :

- `Général`
- `Langues`
- `Lecture audio`
- `Sauvegarde`
- `Mise à jour`

## Comment bien se repérer

Si vous débutez, retenez cette idée simple :

- à droite, vous ouvrez ce que vous voulez lire
- au centre, vous lisez
- à gauche, vous préparez votre travail

## Quand utiliser chaque partie

### Pour lire

Utilisez surtout :

- la colonne de droite
- les onglets
- la vue `Lecture`

### Pour préparer un message

Utilisez surtout :

- `Recherche`
- `Notes`
- `Sujets`
- `Bible`
- `Historique`

### Pour régler l’application

Utilisez :

- `Paramètres`
