# Mises à jour

<p class="lead">Wmb Table peut vérifier si une nouvelle version est disponible afin que vous restiez à jour plus facilement.</p>

## Où vérifier les mises à jour

Ouvrez :

1. `Paramètres`
2. `Mise à jour`

## Vérifier manuellement

Cliquez sur `Vérifier`.

L’application vous indiquera ensuite :

- si une mise à jour est disponible
- si vous êtes déjà à jour
- s’il y a eu une erreur

## Télécharger et installer

Si une nouvelle version est disponible :

1. lancez le téléchargement
2. attendez la fin
3. cliquez sur le bouton d’installation si l’application le demande

## Quand faire la mise à jour

Il est conseillé de mettre l’application à jour :

- quand une nouvelle version est proposée
- quand vous voyez des améliorations utiles
- quand vous avez terminé un travail important en cours

## Conseil avant installation

Avant une mise à jour importante :

- vérifiez que votre sauvegarde est active si vous l’utilisez
- fermez les tâches non nécessaires

## Si la mise à jour échoue

Essayez simplement :

1. de vérifier votre connexion internet
2. de relancer l’application
3. de refaire la vérification plus tard
