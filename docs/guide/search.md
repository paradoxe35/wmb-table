# Faire une recherche

<p class="lead">La recherche vous aide à retrouver très vite une idée, un mot, un lieu ou une expression dans vos prédications.</p>

## Où ouvrir la recherche

Dans le menu de gauche, cliquez sur `Recherche`.

Vous arriverez sur une page dédiée à la recherche dans les prédications.

## Comment lancer une recherche

1. Entrez un mot ou une expression.
2. Tapez au moins trois caractères.
3. Lancez la recherche.
4. Parcourez les résultats.

## Ce que montrent les résultats

Chaque résultat vous donne en général :

- le titre de la prédication
- le nombre de correspondances
- un ou plusieurs extraits
- le numéro du paragraphe ou l’endroit du texte

En cliquant sur un résultat, la prédication s’ouvre et l’application vous rapproche du bon passage.

## Les modes de recherche

La recherche peut fonctionner de plusieurs manières.

### Recherche large

Elle est utile si vous voulez retrouver un sujet général.

### Recherche plus précise

Elle est utile si vous voulez être plus proche de votre expression exacte.

### Quand choisir quel mode

- si vous explorez un thème, choisissez un mode large
- si vous cherchez une phrase bien précise, choisissez un mode plus strict

## Rechercher dans le document ouvert

Quand une prédication est déjà ouverte, vous pouvez aussi rechercher dans ce document seulement.

Cela est utile si :

- vous connaissez déjà la prédication
- vous voulez trouver un passage sans quitter la lecture

## Suggestions enregistrées

L’application retient les recherches utiles pour vous aider à retrouver plus vite ce que vous cherchez souvent.

## Conseils pour bien chercher

- Commencez avec un mot simple.
- Essayez une autre forme du même mot si vous ne trouvez rien.
- Si le résultat est trop large, ajoutez un deuxième mot.
- Si vous ne savez pas dans quelle prédication chercher, commencez par la recherche globale.

## Exemples simples

- chercher un nom de ville
- chercher un thème biblique
- chercher un mot clé du message
- chercher une expression souvent citée

## Après la recherche

Quand vous trouvez un passage utile, vous pouvez :

- l’ouvrir dans la lecture
- l’ajouter à un sujet
- le noter dans une note
- continuer avec la Bible pour comparer
