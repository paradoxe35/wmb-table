# Gérer vos soulignages

<p class="lead">Les soulignages vous permettent de retrouver tous les passages importants que vous avez marqués dans vos lectures. Vous pouvez les consulter, les rechercher et revenir directement au document d'origine.</p>

## À quoi servent les soulignages

Quand vous lisez une prédication, la Bible ou un document personnel, vous pouvez souligner un passage pour le retrouver plus tard.

Tous vos soulignages sont ensuite rassemblés dans un seul endroit : la page **Soulignages**.

Cela vous aide à :

- retrouver rapidement un passage important
- revoir vos passages marqués sans chercher dans chaque document
- retourner directement à l'endroit exact dans la lecture

## Ouvrir la page des soulignages

Dans le menu de gauche, cliquez sur `Soulignages`.

La page affiche la liste de tous vos soulignages, du plus récent au plus ancien.

## Ce que vous voyez pour chaque soulignage

Chaque élément de la liste montre :

- **la couleur** que vous avez choisie (un petit rond coloré)
- **le titre du document** où se trouve le passage
- **le type de document** : prédication, Bible ou document personnel
- **un extrait du texte** souligné
- **votre commentaire**, si vous en avez ajouté un

## Rechercher un soulignage

Si vous avez beaucoup de soulignages, vous pouvez utiliser la barre de recherche en haut de la page.

La recherche cherche dans :

- le titre du document
- le texte souligné
- vos commentaires

Écrivez simplement un mot-clé et les résultats se mettent à jour automatiquement.

## Revenir au document d'origine

Cliquez sur un soulignage dans la liste.

L'application ouvre directement le document correspondant :

- si c'est une prédication, elle s'ouvre dans un onglet
- si c'est un chapitre biblique, il s'ouvre dans un onglet
- si c'est un document personnel, il s'ouvre de la même manière

C'est le moyen le plus rapide de revenir à un passage que vous aviez repéré.

## Supprimer un soulignage

Si un soulignage ne vous sert plus :

1. repérez-le dans la liste
2. cliquez sur le bouton de suppression à droite
3. confirmez

Le passage reste dans le document, mais le marquage de couleur et le commentaire sont retirés.

## Navigation entre les pages

Si vous avez beaucoup de soulignages, la liste est découpée en plusieurs pages.

Utilisez les boutons de navigation en bas de la liste pour passer d'une page à l'autre.

## Comment créer un soulignage

Les soulignages sont créés depuis la vue de lecture, pas depuis cette page.

Voici les étapes :

1. ouvrez une prédication, un chapitre biblique ou un document personnel
2. sélectionnez le texte que vous voulez marquer
3. faites un clic droit
4. choisissez `Souligner`
5. choisissez une couleur
6. ajoutez un commentaire si vous le souhaitez
7. enregistrez

Le passage apparaîtra ensuite ici, dans la page des soulignages.

Le guide complet de la lecture se trouve dans [Utiliser la vue de lecture](/guide/document-view).

## Synchronisation

Si la sauvegarde est activée, vos soulignages sont automatiquement synchronisés entre vos appareils.

Un soulignage créé sur un appareil apparaît sur les autres après la prochaine synchronisation.

## Conseils

- Utilisez des couleurs différentes pour distinguer les types de passages (par exemple, une couleur pour les promesses, une autre pour les exemples).
- Ajoutez un commentaire court pour vous rappeler pourquoi vous avez gardé ce passage.
- Consultez régulièrement vos soulignages pour préparer vos messages.
