# Lire les prédications

<p class="lead">La lecture des prédications est au cœur de Wmb Table. Cette page vous montre comment ouvrir, parcourir et retrouver rapidement un message.</p>

## Ouvrir une prédication

Dans la colonne de droite, ouvrez l’onglet `Prédications`.

Vous pouvez parcourir la bibliothèque :

- par année
- par ordre alphabétique
- par la liste disponible dans la langue active

Cliquez sur un titre pour l’ouvrir au centre.

## Lire au centre

Quand la prédication est ouverte :

- son titre apparaît dans un onglet
- le texte s’affiche paragraphe par paragraphe
- vous pouvez lire tranquillement sans quitter la fenêtre

Pour apprendre en détail la barre du haut, le clic droit, le surlignage, l’ajout à un sujet, l’ajout à une note et la lecture à voix haute, lisez aussi [Utiliser la vue de lecture](/guide/document-view).

## Utiliser plusieurs onglets

Vous pouvez garder plusieurs contenus ouverts en même temps.

Exemples utiles :

- une prédication principale
- une autre prédication pour comparaison
- un chapitre biblique
- un document PDF personnel

Cela aide beaucoup pendant la préparation d’un message.

## Changer de traduction

Certaines prédications peuvent exister dans plusieurs traductions ou langues installées.

Quand cette possibilité existe, l’application permet d’ouvrir la version correspondante pour le même sermon.

Utilisez cela si vous voulez :

- comparer une formulation
- vérifier un passage important
- lire le même sermon dans une autre langue

## Revenir à un passage précis

Wmb Table peut vous ramener à un passage précis depuis :

- la recherche
- un sujet
- une référence dans une note

Vous n’avez donc pas besoin de vous souvenir manuellement de l’endroit.

## Rechercher dans la prédication ouverte

Dans la lecture, vous pouvez lancer une recherche dans le document ouvert.

Cela sert à :

- repérer un mot dans le texte affiché
- passer d’une occurrence à une autre
- mieux retrouver un paragraphe déjà vu

## Surlignage et repères

Pendant la lecture, vous pouvez enregistrer certains passages pour les retrouver plus tard.

Ces repères sont utiles pour :

- marquer un passage important
- le revoir plus tard dans la même lecture
- le réutiliser dans un sujet ou une note

## Zoom et confort de lecture

Si le texte vous semble trop petit ou trop grand, utilisez les commandes de zoom dans la vue de lecture.

Cela permet d’adapter l’affichage à votre écran et à votre confort.

## Audio de la prédication et lecture vocale

Selon le contenu et les réglages :

- certaines prédications peuvent avoir un audio associé
- sinon l’application peut lire le texte avec une voix configurée

Cette partie est détaillée dans [Lecture audio et voix](/guide/audio-and-tts).

## Conseils pratiques

- Gardez peu d’onglets ouverts si vous voulez rester concentré.
- Ouvrez la Bible dans un autre onglet pour comparer plus vite.
- Ajoutez un passage important à un sujet dès que vous le trouvez.
- Si vous avez peur d’oublier, créez une note immédiatement.
