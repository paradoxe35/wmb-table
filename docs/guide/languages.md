# Langues

<p class="lead">Wmb Table fait la différence entre deux types de langues : la langue de votre bibliothèque et la langue de l’interface.</p>

## Deux langues, deux rôles

- **La langue de votre bibliothèque** détermine quelles prédications sont affichées, quelle recherche est utilisée et quelles versions bibliques sont proposées.
- **La langue de l’interface** change les menus, les boutons et les textes de l’application. Vous pouvez choisir entre le français, l’anglais et l’espagnol.

Ces deux réglages sont indépendants. Par exemple, vous pouvez lire des prédications en anglais tout en gardant l’interface en français.

## Ce qu’il faut retenir

Chaque langue installée peut apporter :

- une bibliothèque de prédications
- une recherche adaptée à cette langue
- parfois des contenus et traductions différents

Wmb Table prend en charge un très grand nombre de langues. La base fournie avec l’application contient 81 langues disponibles. C’est pour cela que l’application utilise une fenêtre de gestion des langues : elle vous aide à choisir seulement les langues dont vous avez réellement besoin, au lieu de tout charger d’un seul coup.

## Ouvrir la gestion des langues

Vous pouvez ouvrir cette fenêtre :

- au premier démarrage
- depuis les paramètres
- depuis les raccourcis prévus par l’application

## Pourquoi cette fenêtre est importante

Comme il existe beaucoup de langues disponibles, cette fenêtre sert à :

- voir ce qui est déjà installé
- télécharger seulement ce qui vous est utile
- éviter de vous perdre dans une très grande liste de langues
- passer plus facilement d’une langue à une autre

## Télécharger une langue

1. Ouvrez la gestion des langues.
2. Repérez la langue voulue.
3. Cliquez sur `Télécharger`.
4. Attendez la fin du téléchargement.
5. Cliquez sur la langue pour l’activer.

## Changer la langue de votre bibliothèque

Quand vous activez une autre langue :

- les prédications chargées changent
- les onglets peuvent être gérés séparément pour cette langue
- la recherche se fait sur cette langue

## Ajouter plusieurs langues

Vous pouvez installer plusieurs langues si vous travaillez régulièrement avec plus d’une version.

Exemples :

- français pour la lecture principale
- anglais pour comparer un sermon
- espagnol pour un autre besoin pastoral

## Supprimer une langue

Si vous n’avez plus besoin d’une langue :

1. ouvrez la gestion des langues
2. supprimez la langue voulue

Si c’était votre langue en cours, choisissez-en une autre.

## Conseil important

Installez seulement les langues dont vous avez vraiment besoin au début. Vous pourrez toujours ajouter d’autres langues plus tard.
