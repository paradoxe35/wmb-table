# Utiliser la Bible

<p class="lead">La Bible est intégrée à Wmb Table pour vous aider à lire, comparer et classer vos versets sans quitter votre préparation.</p>

## Ouvrir la Bible

Vous pouvez ouvrir la Bible de deux façons :

- depuis la colonne de droite
- depuis la page `Bible` dans le menu de gauche

## Lire un livre et un chapitre

Dans la partie Bible, choisissez :

1. un testament
2. un livre
3. un chapitre

Le chapitre s’ouvre ensuite dans la zone centrale ou dans la page Bible, selon ce que vous faites.

## Changer de version biblique

La page Bible permet aussi de choisir la version utilisée.

Selon votre langue active, vous pouvez :

- utiliser une version déjà présente
- télécharger une autre version si elle est proposée
- passer d’une version à une autre

## Rechercher un verset

Dans la Bible, vous pouvez rechercher un mot ou une expression.

Vous pouvez aussi limiter la recherche :

- à l’Ancien Testament
- au Nouveau Testament

Les résultats affichent :

- le livre
- le chapitre
- le verset
- le texte contenant le mot recherché

## Ouvrir la Bible dans un onglet

Quand vous ouvrez un chapitre, il peut rester disponible dans un onglet.

C’est pratique pour :

- lire la Bible à côté d’une prédication
- garder plusieurs chapitres sous la main
- revenir d’un onglet à l’autre pendant votre étude

## Aller au chapitre précédent ou suivant

Dans la lecture biblique, vous pouvez passer directement :

- au chapitre précédent
- au chapitre suivant

Cela rend la lecture continue plus agréable.

## Ajouter un verset à un sujet

Quand un verset est important pour votre message, vous pouvez l’ajouter à un sujet.

Cela permet de regrouper dans le même thème :

- des versets
- des références de prédications
- vos idées personnelles dans les notes

## Lecture audio de la Bible

Si une voix est configurée, l’application peut lire les versets à haute voix.

Vous pouvez alors :

- écouter tout le chapitre
- commencer à partir d’un verset
- suivre le texte pendant la lecture

## Quand utiliser la Bible dans Wmb Table

Utilisez-la surtout pour :

- confirmer un passage cité dans une prédication
- préparer un message autour d’un thème
- comparer plusieurs versets rapidement
- classer vos références bibliques dans des sujets
