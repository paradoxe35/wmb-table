# Utiliser la Bible

<p class="lead">La Bible intégrée vous permet de lire, rechercher, comparer et garder des versets utiles sans quitter votre préparation.</p>

## Ouvrir la Bible

Vous pouvez ouvrir la Bible :

- depuis la colonne de droite
- depuis la page `Bible` dans le menu de gauche

## Lire un livre et un chapitre

Le parcours est simple :

1. choisissez un testament
2. choisissez un livre
3. choisissez un chapitre

Le chapitre s’ouvre ensuite dans la lecture.

## Changer de version biblique

Wmb Table peut afficher plusieurs versions bibliques.

Selon votre langue active, vous pouvez :

- utiliser une version déjà installée
- voir d’autres versions disponibles
- télécharger une version distante si elle est proposée
- passer ensuite de l’une à l’autre

Quand une nouvelle version biblique est téléchargée, l’application peut ensuite basculer directement vers elle.

## Les versions distantes

Certaines versions bibliques ne sont pas encore présentes sur votre ordinateur au départ.

Dans ce cas, l’application peut vous montrer un bouton de téléchargement à côté du nom de la version.

Le fonctionnement est simple :

1. ouvrez la Bible
2. regardez la zone des versions
3. si une version n’est pas encore présente, cliquez sur son bouton de téléchargement
4. attendez la fin du téléchargement
5. utilisez ensuite cette version comme les autres

## Rechercher un verset

Dans la Bible, vous pouvez rechercher un mot ou une expression.

Vous pouvez aussi limiter la recherche :

- à l’Ancien Testament
- au Nouveau Testament

Les résultats affichent :

- le livre
- le chapitre
- le verset
- le texte trouvé

## Ouvrir la Bible dans un onglet

Quand vous ouvrez un chapitre, il peut rester disponible dans un onglet.

C’est pratique pour :

- lire la Bible à côté d’une prédication
- garder plusieurs chapitres ouverts
- revenir rapidement d’un texte à l’autre

## Aller au chapitre précédent ou suivant

Dans la lecture biblique, vous pouvez passer directement :

- au chapitre précédent
- au chapitre suivant

Cela rend la lecture continue plus simple.

## Ajouter un verset à un sujet

Quand un verset est important pour votre message, vous pouvez l’ajouter à un sujet.

Cela permet de regrouper ensemble :

- des versets
- des références de prédications
- vos idées de préparation

## Lecture audio de la Bible

Si une voix est configurée, l’application peut lire le chapitre à haute voix.

Vous pouvez alors :

- écouter tout le chapitre
- commencer à partir d’un verset
- suivre le texte pendant la lecture

## Quand la Bible intégrée est la plus utile

Utilisez-la surtout pour :

- confirmer un passage cité dans une prédication
- préparer un message autour d’un thème
- comparer plusieurs versets rapidement
- garder vos références bibliques dans les sujets et les notes
