# Réglages de la vue document

<p class="lead">L’onglet `Vue document` contrôle la manière dont Wmb Table ouvre vos lectures, mémorise la position de lecture et limite le nombre d’onglets.</p>

## Où ouvrir cette page

1. Ouvrez `Paramètres`
2. Cliquez sur `Vue document`

## Ce que vous pouvez régler

Dans cet onglet, vous trouverez surtout deux réglages :

- `Mémoriser la position de lecture`
- `Nombre maximum d'onglets`

## Mémoriser la position de lecture

Quand cette option est activée, Wmb Table peut rouvrir un document là où vous l’aviez laissé.

Cela est utile pour :

- les longues prédications
- les chapitres bibliques
- les documents personnels

Si vous préférez repartir du début à chaque ouverture, désactivez cette option.

## Nombre maximum d'onglets

Vous pouvez fixer une limite pour le nombre d’onglets ouverts en même temps.

Quand la limite est atteinte :

- les onglets les plus anciens peuvent être fermés automatiquement
- votre espace de lecture reste plus clair

## Réglage conseillé

Pour la plupart des utilisateurs :

- laissez la mémorisation de lecture activée
- gardez une limite d’onglets modérée
