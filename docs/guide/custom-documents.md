# Ajouter vos documents PDF

<p class="lead">Wmb Table peut accueillir vos propres documents PDF pour les garder près de vos prédications et de vos notes.</p>

## À quoi servent les documents personnels

Vous pouvez ajouter des PDF comme :

- un plan de message
- un document d’église
- un ancien support d’étude
- un texte de référence

Une fois ajouté, le document peut être ouvert dans l’application.

## Ouvrir la gestion des documents

Dans la colonne de droite, ouvrez l’onglet `Documents`.

S’il n’y a encore rien, un bouton d’ajout est proposé.

## Ajouter un PDF

1. Cliquez sur `Ajouter`.
2. Choisissez un fichier PDF.
3. Vérifiez le nom proposé.
4. Lancez l’ajout.

L’application extrait ensuite le texte du PDF pour le rendre lisible dans Wmb Table.

## Conseils avant l’ajout

- Utilisez de préférence un PDF clair et bien lisible.
- Donnez un nom simple au document.
- Évitez de créer deux documents portant le même nom.

## Ouvrir un document ajouté

Quand le document est prêt :

- il apparaît dans la liste des documents
- vous pouvez cliquer dessus pour l’ouvrir
- il s’ouvre comme un onglet de lecture

## Ce que vous pouvez faire avec un document ajouté

Selon le contenu extrait, vous pouvez :

- le lire dans Wmb Table
- faire une recherche dans le document ouvert
- utiliser la lecture vocale
- ajouter certains passages à vos sujets

## Supprimer un document

Si vous n’avez plus besoin d’un document :

1. ouvrez la gestion des documents
2. repérez le document
3. cliquez sur supprimer

Cette action retire le document de Wmb Table.

## Quand utiliser cette fonction

Cette fonction est très utile si vous voulez garder dans le même espace :

- vos références principales
- vos prédications étudiées
- vos documents de travail personnels
