# Commencer

<p class="lead">Cette page vous aide à utiliser Wmb Table pour la première fois, étape par étape.</p>

## Avant de commencer

Wmb Table fonctionne sur votre ordinateur. Vous n’avez pas besoin de connaissances techniques pour l’utiliser.

Vous aurez surtout besoin de ces éléments :

- un ordinateur sur lequel l’application est déjà installée
- un peu d’espace libre pour télécharger les langues
- une connexion internet si vous voulez télécharger une langue, synchroniser vos données ou vérifier les mises à jour

## Première ouverture

Quand vous ouvrez Wmb Table pour la première fois, l’application vous demande d’abord de choisir une langue.

1. Ouvrez l’application.
2. Attendez que la fenêtre de gestion des langues apparaisse.
3. Téléchargez la langue que vous voulez utiliser.
4. Cliquez sur cette langue pour l’activer.
5. L’application chargera ensuite les prédications de cette langue.

## Ce que vous voyez ensuite

Après le choix de la langue, l’application s’ouvre avec trois grandes zones :

- en haut : la barre principale
- à gauche : les outils comme la recherche, les notes et les paramètres
- à droite : la liste des prédications, la Bible et vos documents personnels

Le centre de la fenêtre sert à la lecture.

## Votre première lecture

Pour ouvrir votre première prédication :

1. Regardez la colonne de droite.
2. Laissez l’onglet `Prédications` ouvert.
3. Recherchez un titre par année, par lettre ou dans la liste.
4. Cliquez sur la prédication souhaitée.
5. Elle s’ouvre au centre dans un onglet.

## Si vous voulez aussi la Bible

Vous pouvez ouvrir la Bible depuis la colonne de droite ou depuis le menu `Bible` à gauche.

Cela vous permet :

- de lire un chapitre
- de rechercher un verset
- de garder la Bible ouverte dans un autre onglet pendant que vous lisez une prédication

## Si vous voulez préparer un message

Les fonctions les plus utiles sont :

- `Recherche` pour retrouver un mot ou une expression
- `Notes` pour écrire vos pensées
- `Sujets` pour classer vos références
- `Historique` pour revenir à ce que vous avez consulté récemment

## Conseils simples pour bien démarrer

- Commencez avec une seule langue, puis ajoutez les autres plus tard.
- Ouvrez quelques prédications importantes dans des onglets.
- Testez une note et un sujet dès le début pour comprendre le fonctionnement.
- Si vous utilisez plusieurs ordinateurs, configurez aussi la sauvegarde.
