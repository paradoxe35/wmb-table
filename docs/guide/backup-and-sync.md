# Sauvegarde et synchronisation

<p class="lead">La sauvegarde protège vos données personnelles et vous aide à les retrouver plus tard, surtout si vous changez d’ordinateur ou si vous utilisez plusieurs machines.</p>

## Ce qui est concerné

La sauvegarde sert surtout pour vos données personnelles, comme :

- les notes
- les sujets
- les documents personnels
- certains réglages utiles

## Où ouvrir cette partie

Ouvrez :

1. `Paramètres`
2. `Sauvegarde`

## Première connexion

Pour commencer :

1. cliquez sur `Connexion Google`
2. connectez-vous avec le compte souhaité
3. autorisez l’accès demandé
4. revenez dans l’application

Après cela, la synchronisation peut démarrer.

## Activer ou mettre en pause

Vous pouvez :

- laisser la synchronisation active
- la mettre en pause temporairement

Si elle est active, l’application essaie de garder vos données à jour.

## Restauration des données

Quand vous vous connectez sur une nouvelle installation ou après récupération, l’application peut restaurer vos données.

Pendant cette étape, vous pouvez voir :

- le début de la restauration
- la progression
- la fin avec demande éventuelle de redémarrage

## Si un message d’erreur apparaît

Les causes les plus courantes sont :

- plus de connexion internet
- session Google expirée
- accès Google refusé ou incomplet

Dans ce cas :

1. vérifiez internet
2. retournez dans `Sauvegarde`
3. reconnectez-vous si nécessaire

## Conseils importants

- Utilisez un seul compte Google pour garder vos données bien regroupées.
- N’attendez pas d’avoir beaucoup travaillé avant d’activer la sauvegarde.
- Si vous voyez une erreur répétée, reconnectez-vous.

## Ce que cette fonction ne remplace pas

Même avec la synchronisation, gardez de bonnes habitudes :

- exportez une note importante en PDF si besoin
- gardez vos documents personnels bien nommés
- vérifiez parfois que la sauvegarde est active
