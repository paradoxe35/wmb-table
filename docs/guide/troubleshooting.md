# Questions et dépannage

<p class="lead">Cette page rassemble les solutions simples aux difficultés les plus courantes.</p>

## Je ne vois aucune prédication

Vérifiez d’abord :

1. qu’une langue est bien installée
2. qu’une langue a bien été choisie

Si nécessaire, ouvrez la gestion des langues et téléchargez-en une.

## La recherche ne trouve rien

Essayez ceci :

1. vérifiez votre langue
2. entrez au moins trois caractères
3. essayez un mot plus simple
4. essayez une autre forme du mot

## Je n’entends pas la lecture audio

Vérifiez :

1. le volume de l’ordinateur
2. les réglages dans `Paramètres > Lecture audio`
3. la voix ou le fournisseur sélectionné
4. que la lecture n’est pas en pause

## Je ne peux pas synchroniser

Vérifiez :

1. votre connexion internet
2. que vous êtes bien connecté à Google
3. que la synchronisation est active

Si besoin, reconnectez-vous dans `Paramètres > Sauvegarde`.

## Une langue ne se télécharge pas

Essayez :

1. de vérifier internet
2. de fermer puis rouvrir l’application
3. de relancer le téléchargement

## Mon document PDF ne s’ajoute pas

Assurez-vous que :

- le fichier est bien un PDF
- le document n’a pas déjà le même nom qu’un autre
- le PDF n’est pas endommagé

## J’ai perdu un repère important

Cherchez d’abord dans :

- l’historique
- les notes
- les sujets

Si vous utilisez la sauvegarde, vérifiez aussi qu’elle est active pour l’avenir.

## Je ferme souvent mes onglets par erreur

Pensez à :

- garder vos éléments importants dans les notes ou les sujets
- utiliser l’historique pour rouvrir ce que vous venez de consulter

## Bonne habitude pour éviter les problèmes

- activez la sauvegarde si vous le pouvez
- donnez des noms clairs à vos notes et à vos documents
- ajoutez vite vos références importantes dans des sujets
- gardez l’application à jour
