# Utiliser la vue de lecture

<p class="lead">La vue de lecture est l’endroit où vous lisez une prédication, un chapitre biblique ou un document personnel. Cette page vous montre, pas à pas, tout ce que vous pouvez faire dans cette zone centrale.</p>

## À quoi sert cette vue

Quand vous ouvrez un contenu, il apparaît au centre de l’application.

Dans cette vue, vous pouvez :

- lire tranquillement paragraphe par paragraphe
- garder plusieurs lectures ouvertes avec des onglets
- rechercher un mot dans le document affiché
- agrandir ou réduire le texte
- écouter l’audio du sermon si disponible
- faire lire le texte à voix haute si aucun audio n’est disponible
- souligner un passage important
- ajouter un passage à un sujet
- lier un passage à une note

## Ce que vous voyez en haut

En haut de la vue de lecture, vous trouvez une petite barre d’actions.

Selon le document ouvert, elle peut afficher :

- la traduction disponible pour ce sermon
- le bouton d’écoute audio du sermon
- le bouton de lecture à voix haute
- les boutons de zoom
- le bouton pour aller directement à un paragraphe
- le bouton de recherche dans le document

## Utiliser les onglets

Chaque lecture ouverte apparaît dans un onglet.

Cela vous permet, par exemple, de garder en même temps :

- une prédication principale
- un chapitre biblique
- une autre prédication pour comparer
- un document PDF personnel

Vous pouvez cliquer sur un onglet pour revenir rapidement à cette lecture.

## Lire et se déplacer dans le texte

Le texte est présenté paragraphe par paragraphe.

Cela rend la lecture plus simple pour :

- repérer un passage précis
- revenir à un paragraphe mentionné ailleurs
- préparer un sujet ou une note à partir d’un passage exact

Si vous voulez aller plus vite vers un endroit précis, utilisez le bouton avec le numéro de paragraphe dans la barre du haut.

Une fenêtre s’ouvre alors avec une liste de numéros. Cliquez sur le numéro voulu pour vous rendre directement à cet endroit.

## Chercher un mot dans le document ouvert

Dans la vue de lecture, vous pouvez chercher un mot sans quitter le document.

Faites simplement ceci :

1. ouvrez le document
2. cliquez sur le bouton de recherche
3. écrivez le mot recherché
4. passez d’un résultat à l’autre

Vous pouvez aussi utiliser le raccourci `Ctrl + F` ou `Cmd + F`.

Cette recherche sert surtout quand vous savez déjà quel document vous lisez et que vous cherchez seulement l’endroit exact.

## Agrandir ou réduire le texte

Si le texte vous paraît trop petit ou trop grand, utilisez les boutons de zoom.

Vous verrez aussi le pourcentage actuel, par exemple `100%`.

Cela vous aide à adapter la lecture à :

- la taille de votre écran
- votre distance par rapport à l’écran
- votre confort personnel

## Écouter ou faire lire le texte

La vue de lecture peut fonctionner de deux façons :

- si la prédication possède déjà un audio, vous pouvez lancer cet audio
- s’il n’y a pas d’audio, l’application peut lire le texte à voix haute

La lecture à voix haute est aussi utile pour :

- les chapitres bibliques
- les documents personnels
- les prédications sans enregistrement audio

Sur certains paragraphes, un petit bouton permet aussi de commencer la lecture à partir de cet endroit précis.

## Changer de traduction d’un sermon

Si plusieurs traductions du même sermon sont disponibles dans vos langues installées, la vue de lecture vous permet de passer de l’une à l’autre.

Cela sert à :

- comparer une phrase
- vérifier un passage important
- lire le même message dans une autre langue

Toutes les prédications n’ont pas forcément plusieurs traductions.

## Ce qui apparaît au début du document

Au début du texte, vous voyez les informations principales du document.

Pour une prédication, cela peut inclure :

- le titre
- la date
- le lieu
- la traduction affichée

Pour un chapitre biblique, vous verrez surtout :

- le nom du livre
- le numéro du chapitre

Pour un document personnel, vous verrez :

- le titre du document

## Faire un clic droit sur un passage

Quand vous sélectionnez un passage ou quand vous faites un clic droit sur un paragraphe, un petit menu apparaît.

Ce menu sert à travailler rapidement sur un passage pendant la lecture.

Les choix les plus importants sont :

- `Copier`
- `Souligner`
- `Ajouter au sujet`
- `Ajouter à la note`
- `Trouver des prédications similaires` (uniquement pour les prédications)

## Copier un passage

Utilisez `Copier` si vous voulez simplement reprendre le texte ailleurs.

Cela peut être utile pour :

- préparer un support
- coller un extrait dans une note
- garder un passage dans un autre document

## Souligner un passage

`Souligner` permet de marquer un passage important directement dans la lecture.

Faites simplement ceci :

1. sélectionnez le texte voulu
2. faites un clic droit
3. choisissez `Souligner`
4. choisissez une couleur
5. ajoutez un commentaire si vous le souhaitez
6. enregistrez

Le commentaire est facultatif. Il peut servir à vous rappeler pourquoi vous avez gardé ce passage.

Tous vos soulignages sont ensuite consultables dans la page **Soulignages** du menu de gauche. Vous pouvez y rechercher, parcourir et revenir directement au document d'origine. Le guide complet se trouve dans [Gérer vos soulignages](/guide/highlights).

## Ajouter un passage à un sujet

`Ajouter au sujet` envoie le passage choisi dans l’un de vos sujets.

Dans la vue de lecture, retenez simplement ceci :

- sélectionnez le passage
- faites un clic droit
- choisissez `Ajouter au sujet`
- choisissez le sujet voulu

Le guide complet se trouve dans [Créer des sujets](/guide/subjects).

## Ajouter un passage à une note

`Ajouter à la note` sert à relier le passage à une note déjà en cours.

Dans la vue de lecture, retenez cette idée simple :

- ouvrez d’abord une note
- créez dans cette note une référence à compléter
- revenez dans la lecture
- sélectionnez le passage
- choisissez `Ajouter à la note`

Le détail complet se trouve dans [Prendre des notes](/guide/notes).

## Trouver des prédications similaires

Quand vous lisez un paragraphe intéressant dans une prédication, vous pouvez découvrir d'autres prédications qui parlent du même sujet.

Faites ceci :

1. faites un clic droit sur le paragraphe qui vous intéresse
2. choisissez `Trouver des prédications similaires`
3. une fenêtre s'ouvre avec les résultats

Chaque résultat montre :

- le titre de la prédication
- la date et le lieu
- les paragraphes similaires avec un extrait du texte

Cliquez sur un paragraphe pour ouvrir cette prédication directement au bon endroit.

Cette fonction est utile pour :

- comparer ce que le prophète a dit sur un sujet dans différentes prédications
- préparer une étude en trouvant des passages liés
- découvrir des prédications que vous n'aviez pas encore lues sur un thème

## Différence entre prédication, Bible et document personnel

La vue de lecture reste presque la même, mais quelques détails changent.

### Pour une prédication

Vous pouvez voir :

- les informations du sermon
- l’audio s’il existe
- le changement de traduction si plusieurs versions sont disponibles
- la navigation par paragraphe

### Pour la Bible

Vous pouvez voir :

- le nom du livre et le chapitre
- les boutons pour passer au chapitre précédent ou suivant
- la lecture à voix haute
- la recherche dans le chapitre ouvert

### Pour un document personnel

Vous pouvez voir :

- le titre du document
- la lecture à voix haute
- la recherche dans le texte
- les mêmes actions de travail sur les paragraphes

## Conseils simples pour bien travailler

- ouvrez la prédication principale dans un onglet
- gardez la Bible dans un autre onglet
- soulignez les passages importants dès que vous les trouvez
- ajoutez un passage à un sujet si vous savez déjà le thème
- utilisez une note si vous voulez préparer un plan plus détaillé
