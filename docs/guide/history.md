# Voir votre historique

<p class="lead">L’historique garde une trace simple de ce que vous avez consulté pour vous aider à revenir rapidement à vos lectures récentes.</p>

## Ouvrir l’historique

Dans le menu de gauche, cliquez sur `Historique`.

L’application regroupe les éléments consultés par jour.

## Ce que vous voyez

L’historique affiche en général :

- la date
- la liste des éléments consultés ce jour-là
- l’heure de consultation

## Ouvrir un élément depuis l’historique

Cliquez simplement sur l’élément voulu.

Cela est utile si :

- vous avez oublié le titre exact
- vous voulez reprendre une étude récente
- vous voulez retrouver rapidement une lecture importante

## Quand l’historique est particulièrement utile

L’historique aide beaucoup :

- après plusieurs jours d’étude
- quand plusieurs onglets ont été fermés
- quand vous avez consulté beaucoup de prédications dans la même journée

## Bonne pratique

Si un passage est très important, ne vous reposez pas seulement sur l’historique.

Ajoutez-le aussi :

- à une note
- à un sujet

Ainsi, vous ne dépendrez pas seulement de la date de consultation.
