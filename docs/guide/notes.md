# Prendre des notes

<p class="lead">Les notes vous permettent de garder vos idées, vos plans de prédication et vos références dans un seul endroit.</p>

## Ouvrir les notes

Dans le menu de gauche, cliquez sur `Notes`.

Vous verrez la liste de vos notes existantes, avec la possibilité d’en créer une nouvelle.

## Créer une note

1. Cliquez sur `Nouvelle note`.
2. Ouvrez la note créée.
3. Donnez-lui un nom clair.
4. Commencez à écrire.

Si vous laissez une note vide puis revenez en arrière, l’application peut vous demander si vous voulez la supprimer.

## Renommer une note

Pendant que la note est ouverte :

- cliquez sur le nom ou le bouton de renommage
- saisissez le nouveau nom
- enregistrez

Donnez des noms simples, par exemple :

- `Message du dimanche`
- `Étude sur la foi`
- `Références pour Actes 2`

## Écrire dans l’éditeur

L’éditeur sert à écrire librement :

- vos idées
- votre plan
- vos citations
- vos références importantes

Vous pouvez préparer une note simple ou un contenu plus complet.

## Ajouter des références à une note

Les notes peuvent contenir des références utiles vers :

- des passages de prédications
- des références bibliques

Ces liens vous permettent d’ouvrir plus tard le contenu lié sans avoir à le rechercher à nouveau.

## Ouvrir une référence depuis une note

Quand une référence est dans la note :

- cliquez dessus
- l’application affiche le détail ou ouvre le contenu associé

Cela vous aide à relire rapidement vos sources.

## Mode lecture

Si vous voulez simplement relire votre note sans la modifier, vous pouvez activer le mode lecture.

## Exporter la note en PDF

Quand votre note est prête, vous pouvez l’exporter au format PDF.

Cette fonction est utile pour :

- imprimer votre plan
- partager votre note
- garder une copie séparée

## Conseils pour de bonnes notes

- Une note par message ou par thème.
- Utilisez un nom court et clair.
- Ajoutez les références importantes dès que vous les trouvez.
- Si un groupe de références revient souvent, créez aussi un sujet.
