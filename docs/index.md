## Description complète de Wmb Table

Wmb Table est une application de bureau conçue pour aider à lire et étudier les prédications de William Marrion Branham de façon simple et ordonnée. Elle réunit dans un même espace la lecture des prédications, la Bible, les notes personnelles, les sujets, la recherche, les documents PDF, l’audio et la sauvegarde des données.

L’objectif n’est pas de donner un outil compliqué. L’objectif est de permettre à un pasteur, un prédicateur ou un frère en charge d’un message de retrouver rapidement une référence, de classer ses pensées, de relire un passage important et de garder son travail en sécurité.

> [!TIP]
> Si vous utilisez Wmb Table pour la première fois, commencez par [Commencer](/guide/getting-started).
