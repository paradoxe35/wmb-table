## Reportar un error

Si encuentra un problema en la aplicación, así es como puede ayudarnos a resolverlo rápidamente:

1. **Describa el problema**: ¿qué ocurrió? ¿Qué esperaba?
2. **Pasos para reproducir**: ¿qué acciones realizó antes de que apareciera el problema?
3. **Su sistema**: ¿Windows, macOS o Linux? ¿Qué versión de la aplicación?
4. **Capturas de pantalla**: si es posible, adjunte una imagen que muestre el problema.

También puede enviar el reporte del error directamente por correo con esta información.
