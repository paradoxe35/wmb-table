# Lectura en audio y voces

<p class="lead">Wmb Table puede leer el texto en voz alta cuando usted quiere escuchar una predicación, un capítulo bíblico o un documento personal.</p>

## Para qué sirve

La lectura en audio es útil para:

- escuchar una predicación
- escuchar un capítulo bíblico
- escuchar un documento personal
- seguir el texto mientras se lee

Es especialmente importante cuando una predicación no tiene audio propio.

## Dónde abrirla

1. Abra `Ajustes`
2. Haga clic en `Lectura en audio`

## Proveedores disponibles

La aplicación puede usar:

- voces del sistema
- Sherpa-ONNX TTS
- Kokoro TTS
- Edge TTS (Microsoft)
- ElevenLabs TTS
- OpenAI TTS

`Edge TTS (Microsoft)` ya está disponible y es útil si usted quiere muchas voces y muchos idiomas sin crear una cuenta.
