# Lectura en audio y voces

<p class="lead">Wmb Table puede leer el texto en voz alta cuando usted quiere escuchar una predicación, un capítulo bíblico o un documento personal.</p>

## Para qué sirve

La lectura en audio es útil para:

- escuchar una predicación
- escuchar un capítulo bíblico
- escuchar un documento personal
- seguir el texto mientras se lee

Es especialmente importante cuando una predicación no tiene audio propio.

## Dónde abrirla

1. Abra `Ajustes`
2. Haga clic en `Lectura en audio`

## Proveedores disponibles

La aplicación puede usar:

- voces del sistema
- Sherpa-ONNX TTS
- Edge TTS (Microsoft)
- Cartesia TTS
- ElevenLabs TTS
- OpenAI TTS

`Edge TTS (Microsoft)` ya está disponible y es útil si usted quiere muchas voces y muchos idiomas sin crear una cuenta.

Para los proveedores de pago, puede obtener una clave API en:

- Cartesia: [play.cartesia.ai/keys](https://play.cartesia.ai/keys)
- ElevenLabs: [elevenlabs.io/app/developers/api-keys](https://elevenlabs.io/app/developers/api-keys)
- OpenAI: [platform.openai.com/api-keys](https://platform.openai.com/api-keys)

## Lectura mejorada

Estos ajustes hacen la lectura más natural y práctica.

### Leer la introducción

Antes de leer el contenido, la aplicación anuncia el título del documento. Para una predicación, puede decir la fecha y el lugar. Para un capítulo bíblico, dice el nombre del libro y el número del capítulo.

Puede desactivar esta opción si prefiere ir directamente al texto.

### Anunciar los números

La aplicación puede decir el número del versículo o del párrafo antes de leerlo. Por ejemplo: « Versículo 5 », luego el contenido.

Esto es útil para seguir la lectura sin mirar la pantalla.

### Leer todo el libro (Biblia)

Cuando escucha un capítulo bíblico, la aplicación puede pasar automáticamente al siguiente capítulo cuando termina la lectura. Continúa hasta el último capítulo del libro.

Este ajuste solo se aplica a la Biblia.

### Desplazamiento automático

Durante la lectura, la página se desplaza para mantener visible el texto que se está leyendo.

Si prefiere desplazarse usted mismo, puede desactivar esta opción.
