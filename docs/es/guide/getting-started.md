# Primeros pasos

<p class="lead">Esta página le ayuda a usar Wmb Table por primera vez, paso a paso.</p>

## Antes de comenzar

Wmb Table funciona en su computadora. No necesita experiencia técnica para usarlo.

Necesita principalmente:

- una computadora donde la aplicación ya esté instalada
- algo de espacio libre para descargar idiomas
- conexión a internet si quiere descargar un idioma, sincronizar datos o buscar actualizaciones

## Primer inicio

Cuando abre Wmb Table por primera vez, la aplicación primero le pide elegir un idioma.

1. Abra la aplicación.
2. Espere a que aparezca la ventana de idiomas.
3. Descargue el idioma que desea usar.
4. Haga clic en ese idioma para activarlo.
5. La aplicación cargará entonces las predicaciones de ese idioma.

## Lo que verá después

Después de elegir el idioma, la aplicación se abre con tres áreas principales:

- arriba: la barra principal
- a la izquierda: herramientas como búsqueda, notas y ajustes
- a la derecha: predicaciones, Biblia y sus propios documentos

La parte central sirve para la lectura.
