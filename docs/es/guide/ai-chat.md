# Chat con IA

<p class="lead">Wmb Table incluye una función de chat con IA para ayudar a encontrar información más rápido y preparar temas con mayor facilidad.</p>

> [!IMPORTANT]
> Esta función no está activada por defecto. Debe activarse de forma voluntaria en la pestaña `Assistant` de los ajustes.

## Para qué sirve

Puede ayudar a:

- explorar temas existentes
- crear nuevos temas
- encontrar referencias bíblicas
- encontrar documentos y predicaciones
- encontrar notas
- agregar referencias a temas
- buscar sermones por título, fecha, ciudad y otros datos disponibles

## Cuándo es útil

Será especialmente útil cuando usted quiera:

- encontrar un pasaje rápidamente sin repetir muchas búsquedas
- preparar un tema usando varias fuentes
- comprobar si ya tiene una nota o un tema sobre un asunto
- encontrar una predicación a partir de información incompleta

## Uso sencillo

Cuando esta función está activada, el uso es simple:

1. abrir la página o panel `Chat con IA`
2. escribir una petición con palabras sencillas
3. leer la respuesta
4. abrir la predicación, el versículo, la nota o el tema encontrado
5. agregar una referencia a un tema si el resultado es correcto

## Ejemplos de buenas peticiones

- `Muéstrame los temas sobre la fe`
- `Agrega Juan 3:16 a mi tema Salvación`
- `Busca predicaciones predicadas en Jeffersonville`
- `Busca mis notas sobre la simiente`
- `Encuentra sermones por fecha sobre el bautismo`

## Lo que podrá hacer con los temas

Deberá ayudar a:

- listar temas existentes
- verificar si ya hay un tema parecido
- crear un nuevo tema
- agregar referencias bíblicas a un tema
- agregar referencias de predicaciones a un tema
- volver a abrir el contenido ya guardado en un tema

## Lo que podrá hacer con las predicaciones

Deberá poder buscar sermones por:

- título
- fecha
- ciudad o lugar
- otros datos ya disponibles en la aplicación

## Lo que podrá hacer con las notas

También deberá poder:

- encontrar notas existentes
- sugerir notas relacionadas con el tema pedido
- ayudar a reabrir una nota más rápido

## Idioma activo

La IA tendrá en cuenta el idioma activo de la aplicación para ofrecer resultados más útiles y más cercanos a su contexto de trabajo.

## Activación de la función

Esta función existe en la aplicación, pero permanece desactivada por defecto.

Para usarla:

1. abra `Ajustes`
2. abra la pestaña `Assistant`
3. active el asistente
4. abra después la página de chat con IA

## Modelos y recomendación automática

Se pueden usar varios proveedores y modelos detrás de la función. Para el usuario, lo importante es esto:

- la aplicación ofrece varios modelos
- la aplicación podrá recomendar automáticamente el más adecuado
- el objetivo es ahorrar tiempo sin exigir conocimientos técnicos

## Uso seguro

Antes de guardar un resultado:

1. abra la fuente propuesta
2. lea el pasaje dentro de su contexto
3. confirme que el idioma activo es el correcto
4. agregue solo las referencias realmente útiles
