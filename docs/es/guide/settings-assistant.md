# Ajustes de Assistant

<p class="lead">La pestaña `Assistant` sirve para activar y configurar la función de chat con IA en Wmb Table.</p>

> [!IMPORTANT]
> La función Assistant existe en la aplicación, pero no se activa automáticamente. Esta pestaña sirve para ponerla en marcha y ajustarla.

## Dónde abrirla

1. Abra `Ajustes`
2. Haga clic en `Assistant`

## Para qué sirve esta pestaña

Permite:

- activar o desactivar el asistente
- ver si la función está disponible
- gestionar las opciones relacionadas con el asistente
- preparar el uso del chat con IA

## Flujo para el usuario

El recorrido es simple:

1. abrir `Ajustes`
2. entrar en `Assistant`
3. activar la función
4. guardar o confirmar las opciones necesarias
5. abrir después la página de chat con IA
