# Agregar documentos PDF

<p class="lead">Wmb Table puede guardar sus propios documentos PDF para tenerlos cerca de las predicaciones y las notas.</p>

## Abrir la gestión de documentos

En el panel derecho, abra `Documentos`.

<ScreenshotPlaceholder
  file="es-custom-documents-modal.png"
  label="Ventana de gestión de documentos PDF"
  hint="Mostrar la lista de documentos, la búsqueda, el botón Agregar y las acciones ver/eliminar."
/>

## Agregar un PDF

1. Haga clic en `Agregar`.
2. Elija un archivo PDF.
3. Revise el nombre propuesto.
4. Inicie la importación.

Luego el texto se extrae para poder leerse dentro de Wmb Table.
