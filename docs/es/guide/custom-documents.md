# Agregar documentos PDF

<p class="lead">Wmb Table puede guardar sus propios documentos PDF para tenerlos cerca de las predicaciones, la Biblia y las notas.</p>

## Abrir la gestión de documentos

En el panel derecho, abra `Documentos`.

  file="es-custom-documents-modal.png"

## Agregar un PDF

1. Haga clic en `Agregar`.
2. Elija un archivo PDF.
3. Revise el nombre propuesto.
4. Elija el idioma del documento si hace falta.
5. Inicie la importación.

El nombre puede proponerse automáticamente a partir del nombre del archivo. Usted puede cambiarlo antes de importar si quiere un título más limpio.

Luego el texto se extrae para poder leerse dentro de Wmb Table.

## Qué puede hacer con un documento agregado

Según el texto extraído, puede:

- leerlo dentro de Wmb Table
- buscar dentro del documento abierto
- usar la lectura en voz alta
- ir directamente a un párrafo
- agregar pasajes a temas
- agregar pasajes a notas
