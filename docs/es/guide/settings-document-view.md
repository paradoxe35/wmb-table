# Ajustes de la vista de lectura

<p class="lead">La pestaña `Vista de lectura` controla cómo Wmb Table abre sus lecturas, recuerda la posición y limita el número de pestañas abiertas.</p>

## Dónde abrirla

1. Abra `Ajustes`
2. Haga clic en `Vista de lectura`

## Qué puede configurar

En esta pestaña encontrará sobre todo dos ajustes:

- `Recordar la posición de lectura`
- `Número máximo de pestañas`

## Recordar la posición de lectura

Cuando esta opción está activada, Wmb Table puede volver a abrir un documento donde usted lo dejó.

Es útil para:

- predicaciones largas
- capítulos bíblicos
- documentos personales

Si prefiere abrir siempre desde el principio, desactive esta opción.

## Número máximo de pestañas

Puede fijar un límite para la cantidad de pestañas de lectura abiertas al mismo tiempo.

Cuando se alcanza el límite:

- las pestañas más antiguas pueden cerrarse automáticamente
- el espacio de trabajo queda más limpio
