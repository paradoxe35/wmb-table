## Signaler un bug

Si vous rencontrez un problème dans l'application, voici comment nous aider à le résoudre rapidement :

1. **Décrivez le problème** : que s'est-il passé ? Qu'attendiez-vous ?
2. **Étapes pour reproduire** : quelles actions avez-vous faites avant que le problème apparaisse ?
3. **Votre système** : Windows, macOS ou Linux ? Quelle version de l'application ?
4. **Captures d'écran** : si possible, ajoutez une image qui montre le problème.

Vous pouvez aussi nous envoyer le rapport directement par email avec ces informations.
