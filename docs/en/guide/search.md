# Searching

<p class="lead">Search helps you quickly find an idea, a word, a place, or an expression inside your sermons.</p>

## Opening search

In the left menu, click `Search`.

## How to search

1. Enter a word or expression.
2. Use at least three characters.
3. Start the search.
4. Review the results.

## What the results show

Each result usually includes:

- the sermon title
- the number of matches
- one or more snippets
- the paragraph or place in the text

When you click a result, the sermon opens and the app moves closer to the right passage.

## Search modes

Search offers three modes. You can change them with the selector next to the search box.

### All words

This is the default mode. All the words you type must appear in the same paragraph. For example, `Revelation 10` will find paragraphs that contain both "Revelation" and "10".

### Any word

At least one of the words must appear. This mode is broader and returns more results. Useful when you are exploring a theme without knowing the exact term the prophet used.

### Exact phrase

The words must appear in order and close to each other, like a phrase. For example, `the paradox` will find passages that contain this expression as it is.

### Typo tolerance

The search handles small typing mistakes. If you type `apocalipse` instead of `apocalypse`, results will still appear. Matched words are highlighted in the results.

## Search inside the current document

If a sermon is already open, you can also search only in that document.

## Useful advice

- Start with a simple word.
- If you get too many results, add a second word.
- If you get nothing, try another form of the same word.
- If you do not know which sermon to open, begin with the global search page.
