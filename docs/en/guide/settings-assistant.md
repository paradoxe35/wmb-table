# Assistant Settings

<p class="lead">The `Assistant` tab is used to enable and configure the AI chat feature in Wmb Table.</p>

> [!IMPORTANT]
> The Assistant feature exists in the app, but it does not turn on automatically. This tab is where users enable it and adjust it.

## Where to open it

1. Open `Settings`
2. Click `Assistant`

## What this tab does

This tab allows users to:

- enable or disable the assistant
- see whether the feature is available
- manage assistant-related settings
- prepare the AI chat for use

## User flow

The flow is simple:

1. open `Settings`
2. enter `Assistant`
3. enable the feature
4. save or confirm the needed options
5. then open the AI chat page

## What users should check

Before using the assistant, users should be able to confirm:

- that the feature is enabled
- that the active language is correct
- that the assistant settings match their need
