# General Settings

<p class="lead">The `General` tab gives a quick summary of the application state. It is the best place to check at a glance whether everything is set correctly.</p>

## Where to open it

1. Open `Settings`
2. Click `General`

## What you can see there

This page mainly gathers summary information:

- the content language
- the number of installed languages
- backup status
- update status

## What this page is for

Use it when you want to:

- confirm the content language
- check whether backup is working
- see whether an update is available
- review the overall application state without opening every other tab
