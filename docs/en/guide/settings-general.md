# General Settings

<p class="lead">The `General` tab gives a quick summary of the application state, but it also holds the basic controls for appearance, text size, and interface language.</p>

## Where to open it

1. Open `Settings`
2. Click `General`

## What you can see there

This page combines two things:

- simple preferences many users change early
- a quick overview of the application state

You can see for example:

- the appearance mode
- the text size
- your library language
- the interface language
- the number of installed languages
- backup status
- update status

## Appearance

You can choose between four modes:

- `Auto`: light by day, dark in the evening
- `System`: follows your computer appearance
- `Light`
- `Dark`

## Text size

You can also choose the text size:

- `Small`
- `Normal`
- `Large`
- `Extra large`

## Interface language

The interface language controls:

- menus
- buttons
- messages shown in the app

It is different from your sermon library language.

## What this page is for

Use it when you want to:

- confirm your library language
- check the interface language
- switch quickly between light, dark, auto, or system appearance
- make the text larger if needed
- check whether backup is working
- see whether an update is available
- review the overall application state without opening every other tab

## Helpful reminders

If some important features are still not configured, Wmb Table may later show a small non-blocking notification at the top of the app to remind you about:

- AI Assistant
- Audio Reading
- Backup

You can click the reminder to open the correct settings tab, or close it and let the app remind you again later.
