# Languages

<p class="lead">Languages in Wmb Table are not only for the screen. They also control the sermons and search data you work with.</p>

## Important idea

Each installed language can bring:

- a sermon library
- search adapted to that language
- different translations or available content

French is the default app language, but English and Spanish can also be used when installed.

## Opening language management

You can open it:

- at first launch
- from settings
- from the language shortcuts provided by the app

## Downloading a language

1. Open language management.
2. Find the language you want.
3. Click `Download`.
4. Wait for the download to finish.
5. Click the language to make it active.

## Changing the active language

When you switch language:

- the loaded sermons change
- tabs can be handled separately for that language
- search runs in that language
