# Adding PDF Documents

<p class="lead">Wmb Table can store your own PDF documents so they stay close to your sermons and notes.</p>

## What this is for

You can add PDFs such as:

- a sermon outline
- a church document
- an older study file
- a personal reference text

## Opening document management

In the right panel, open the `Documents` tab.

  file="en-custom-documents-modal.png"

## Adding a PDF

1. Click `Add`.
2. Choose a PDF file.
3. Check the proposed name.
4. Start the import.

The app then extracts the text so it can be read inside Wmb Table.

## Opening an added document

When the document is ready, click it and it opens in a reading tab.

## What you can do with it

Depending on the extracted content, you can:

- read it
- search inside the open document
- use voice reading
- add passages to subjects
