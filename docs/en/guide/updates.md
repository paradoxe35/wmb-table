# Updates

<p class="lead">Wmb Table can check for new versions so you can keep the application up to date more easily.</p>

## Where to check

Open:

1. `Settings`
2. `Update`

## Checking manually

Click `Check`.

The application will tell you whether:

- an update is available
- you are already up to date
- an error happened

## Downloading and installing

If a new version is available:

1. start the download
2. wait until it finishes
3. click the install button if the application asks for it
