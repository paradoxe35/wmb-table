# Taking Notes

<p class="lead">Notes let you keep your ideas, sermon outlines, and references in one place.</p>

## Opening notes

In the left menu, click `Notes`.

<ScreenshotPlaceholder
  file="en-notes-list-page.png"
  label="Notes list"

/>

## Creating a note

1. Click `New note`.
2. Open the note.
3. Give it a clear name.
4. Start writing.

## Renaming a note

While the note is open:

- click the note name or rename button
- type the new name
- save it

## Writing in the editor

The editor can hold:

- your ideas
- your sermon outline
- quotations
- important references

## Adding references inside a note

Notes can contain links to:

- sermon passages
- Bible references

## Opening a reference from a note

When you click a reference, the app can show the detail or open the linked content.

## Reading mode

If you only want to review the note without editing it, you can switch to reading mode.

## Exporting to PDF

When the note is ready, you can export it as a PDF.
