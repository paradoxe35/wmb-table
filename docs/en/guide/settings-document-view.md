# Document View Settings

<p class="lead">The `Document View` tab controls how Wmb Table opens your readings, remembers your reading position, and limits the number of open tabs.</p>

## Where to open it

1. Open `Settings`
2. Click `Document View`

## What you can configure

This tab mainly contains two settings:

- `Remember reading position`
- `Maximum number of tabs`

## Remember reading position

When this option is enabled, Wmb Table can reopen a document where you left it.

This is useful for:

- long sermons
- Bible chapters
- personal documents

If you prefer every document to open from the top again, turn it off.

## Maximum number of tabs

You can set a limit for how many reading tabs stay open at the same time.

When the limit is reached:

- the oldest tabs can be closed automatically
- your workspace stays cleaner
