# Settings Overview

<p class="lead">This page shows clearly what the Wmb Table settings are for and when to open each section.</p>

## Where to find settings

In the left menu, click `Settings`.

The settings page contains several simple tabs:

- `General`
- `Document View`
- `Library`
- `Assistant`
- `Audio Reading`
- `Backup`
- `Update`

## What each tab is for

### General

This gives you a quick summary of the application state.

You can see things like:

- the appearance mode
- the text size
- your library language
- the interface language
- the number of installed languages
- backup status
- update status

### Document View

Use this section to control the reading experience itself.

It lets you:

- decide whether reading position is remembered
- choose the maximum number of open tabs

### Library

Use this section to:

- see installed languages
- open full language management
- change your library language

### Assistant

This section is used for the AI feature.

It lets you:

- choose the AI provider
- configure a local model or an online service
- control language behavior

After you have started using the app, Wmb Table may also show a small reminder for this feature if it is still not configured.

### Audio Reading

Use this section to:

- choose the voice or reading service
- test a voice
- change the reading speed
- choose the highlight mode
- manage the audio cache

Wmb Table can also remind you about this later if you have never configured or used it.

### Backup

Use this section to:

- sign in with Google
- enable or pause sync
- review backup status
- follow data restore progress

The app can also remind you about backup later if it has never been configured.

### Update

Use this section to:

- check for a new version
- start downloading it
- install the update when ready

## Which tab should you open

If you want to…

- make a quick check: open `General`
- manage tab behavior or reading resume: open `Document View`
- change your library language: open `Library`
- set up AI chat: open `Assistant`
- listen to a sermon or Bible chapter: open `Audio Reading`
- protect your work: open `Backup`
- install the latest version: open `Update`

## Good order for a new user

For a new user, the simplest order is:

1. `Library` to choose your language
2. `Document View` if you want to adjust tabs and reading resume
3. `Assistant` when you want to use the AI feature
4. `Audio Reading` if you want voice reading
5. `Backup` if you want to secure your work
6. `Update` from time to time
