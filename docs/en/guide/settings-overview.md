# Settings Overview

<p class="lead">This page shows clearly what the Wmb Table settings are for and when to open each section.</p>

## Where to find settings

In the left menu, click `Settings`.

The settings page contains several simple tabs:

- `General`
- `Languages`
- `Assistant`
- `Audio Reading`
- `Backup`
- `Update`

## What each tab is for

### General

This gives you a quick summary of the application state.

You can see things like:

- the content language
- the number of installed languages
- backup status
- update status

### Languages

Use this section to:

- see installed languages
- open full language management
- change your working language

### Assistant

This section is used for the AI feature.

It should allow the user to:

- enable or disable the assistant
- manage assistant-related options
- review how the assistant should be used

If you want to use AI chat, this is the first tab to open.

### Audio Reading

Use this section to:

- choose the voice or reading service
- test a voice
- change the reading speed
- choose the highlight mode
- manage the audio cache

### Backup

Use this section to:

- sign in with Google
- enable or pause sync
- review backup status
- follow data restore progress

### Update

Use this section to:

- check for a new version
- start downloading it
- install the update when ready

## Which tab should you open

If you want to…

- change language: open `Languages`
- use or enable AI chat: open `Assistant`
- listen to a sermon or Bible chapter: open `Audio Reading`
- protect your work: open `Backup`
- install the latest version: open `Update`
- make a quick check: open `General`

## Good order for a new user

For a new user, the simplest order is:

1. `Languages`
2. `Assistant` when you want to use the AI feature
3. `Audio Reading` if you want voice reading
4. `Backup` if you want to secure your work
5. `Update` from time to time
