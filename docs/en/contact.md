## Report a bug

If you encounter a problem in the application, here's how to help us fix it quickly:

1. **Describe the problem**: what happened? What did you expect?
2. **Steps to reproduce**: what actions did you take before the problem appeared?
3. **Your system**: Windows, macOS, or Linux? Which version of the application?
4. **Screenshots**: if possible, attach an image showing the problem.

You can also send the bug report directly by email using the details above.
